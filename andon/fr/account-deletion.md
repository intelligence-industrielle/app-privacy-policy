# Suppression du compte — Andon

Cette page explique comment supprimer votre compte Andon et ce qui est supprimé. Andon est une application d'Intelligence Industrielle inc. pour les employés de ses organisations clientes.

## 1. Depuis l'application (recommandé)

1.  Ouvrez **Andon** et connectez-vous.
2.  Touchez le **cercle à vos initiales**, en haut à droite (menu de votre profil).
3.  Touchez **Supprimer mon compte**.
4.  Pour confirmer, écrivez **SUPPRIMER**, puis touchez **Supprimer définitivement**.

La suppression est **immédiate et définitive** : vous êtes déconnecté de tous vos appareils et ne pouvez plus vous connecter avec ce compte. Elle ne peut pas être annulée.

## 2. Si vous n'avez plus accès à l'application

Écrivez à **achats@intelligenceindustrielle.com**, objet « Suppression de compte Andon », depuis l'adresse courriel de votre compte. Nous supprimons le compte et vous le confirmons dans un délai de 30 jours. Votre organisation, qui gère votre compte, peut aussi le supprimer.

## 3. Ce qui est supprimé

*   **Votre compte** : nom, adresse courriel, rôle et accès, sur la plateforme d'Intelligence Industrielle.
*   **Vos sessions** : toutes vos connexions, sur tous vos appareils, sont fermées.
*   **Votre téléphone** : il est retiré des notifications d'Andon.
*   **Sur l'appareil** : vos jetons de connexion sont effacés tout de suite ; les autres données gardées par l'application (réglages, derniers appels hors ligne) disparaissent quand vous la désinstallez.

## 4. Ce qui est gardé

*   **Les données de travail de votre organisation** : les appels Andon (poste, type d'appel, heures, commentaires) appartiennent à votre organisation et restent dans son historique, selon son contrat avec Intelligence Industrielle.
*   **Votre fiche dans l'équipe de l'usine** (nom, téléphone pour les alertes), créée par votre organisation : elle est retirée par un administrateur de votre organisation, ou par nous sur demande à l'adresse ci-dessus.

Politique de confidentialité : [Andon — politique de confidentialité](https://github.com/intelligence-industrielle/app-privacy-policy/blob/main/andon/fr/privacy-policy.md).
